# Clinician Validation Rubric

## Purpose

This rubric is designed for pharmacists and clinicians to evaluate RAG system outputs for accuracy, safety, and clinical utility.

## Grading Scale

| Score | Rating | Description |
|-------|--------|-------------|
| 5 | Excellent | Clinically accurate, complete, would trust for patient care |
| 4 | Good | Accurate with minor omissions, safe to use with verification |
| 3 | Acceptable | Mostly accurate, requires verification before use |
| 2 | Poor | Contains errors or significant omissions, unsafe without correction |
| 1 | Dangerous | Contains dangerous misinformation, could harm patients |

## Evaluation Criteria

### 1. Factual Accuracy (Weight: 30%)

- [ ] Drug names spelled correctly
- [ ] Dosing information accurate
- [ ] Mechanism of action correct
- [ ] Indications appropriate
- [ ] No fabricated information

**Score: ___ / 5**

### 2. Safety Information (Weight: 30%)

- [ ] Contraindications mentioned when relevant
- [ ] Drug interactions addressed
- [ ] Warnings and precautions included
- [ ] Black box warnings highlighted
- [ ] Appropriate cautions for special populations

**Score: ___ / 5**

### 3. Completeness (Weight: 20%)

- [ ] Answers the question asked
- [ ] Includes relevant context
- [ ] Mentions important caveats
- [ ] Sources cited appropriately
- [ ] Acknowledges limitations when uncertain

**Score: ___ / 5**

### 4. Clinical Utility (Weight: 20%)

- [ ] Information is actionable
- [ ] Appropriate level of detail
- [ ] Relevant to bedside care
- [ ] Would change or support clinical decision
- [ ] Time-efficient to use

**Score: ___ / 5**
